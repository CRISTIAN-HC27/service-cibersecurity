    Cómo está protegida esta interfaz

    • El access token (15 min) vive solo en memoria: no hay localStorage que robar.
    • El refresh token es una cookie HttpOnly; SameSite=Strict; Path=/auth/refresh: el navegador la envía sola y el JS no puede leerla.
    • La renovación es de un solo uso: reutilizar un refresh ya canjeado revoca toda la sesión (REUSE_DETECTED).
    • Las peticiones con cookie validan Origin contra la whitelist (protección CSRF).
